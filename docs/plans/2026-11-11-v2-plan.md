# DaVinci Storage v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use `- [ ]`.

**Goal:** library backups before cleanup (+rotation), project-backup trimming, LUT duplicates with usage protection, Magic Mask setting check, «Не чіпати», logs/crash reports.

**Architecture:** new pure-Foundation units in `StorageCore` (each its own file + tests); the app wires them into the existing `AppModel` and views. No change to Cleaner's library rule.

**Tech Stack:** Swift 6.4 CLT, SwiftPM, SQLite3, CryptoKit (SHA-256), Swift Testing. No `@State` (use `Box`/AppModel).

**Spec:** `docs/specs/2026-11-11-v2-backups-luts-design.md`

## Global Constraints
- Defaults: backupFolder `~/DAVINCI_DATA_BASE/_BACKUPS`, keepLibraryBackups 10, keepProjectBackups 3.
- Backup folder name: `yyyy-MM-dd HH-mm · DaVinci Resolve <version>`; marker file `.davinci-storage-backup` (JSON).
- Copy only `<library root>/Resolve Projects` into `<backup>/<library name>/Resolve Projects`.
- Everything removed goes to the Trash (`trashItem`); rotation only touches folders with the marker.
- UI strings Ukrainian.

## Review Focus
1. Backup target inside a `Resolve Projects` folder → refused (no recursion). (T2 `refusesTargetInsideLibrary`)
2. Copy verification fails → no partial backup left, cleanup aborted. (T2 `failedVerificationLeavesNothing`)
3. Rotation never touches folders without marker. (T2 `rotationIgnoresForeignFolders`)
4. A LUT whose file name appears in any project is never selectable. (T5 `usedLutNotSelectable`)
5. Protected project's items (incl. shared) never auto-selected, incl. old backups. (T4/T3 tests)
